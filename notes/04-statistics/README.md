Statistics:

Estimation - The process of using sample data to approximiate unknown population parameters

Expected Total Error = (Bias)^2 + Variance + Irreducible Error
 - Bias = Expected Prediction - True Value
 - Variance = Expected Squared Variation of Predictions Around Their Mean
 - Irreducible Error = Variance of the Inherent Data Noise (Sigma^2)

Confidence Intervals - Range of values, calculated from sample data, that is likely to
                       contain the true value of an unknown population paramter.
                    
Hypothesis testing - Statistical method used to decide if sample data gives enough evidence
                     to support a specific claim about a whole population.

Maximum Likelihood Estimation - Method in statistics used to find the best-fit parameters for
                                a data population. Works by calculating the parameter values that make observed real-world data show the highest possible chance of occuring under a chosen model.
                            
Regression - Statistical method used to model the relationship between a dependent variable
             and one or more independent variables.
